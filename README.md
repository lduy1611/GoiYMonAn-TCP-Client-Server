# GoiYMonAnTCP

TCP core for the “Hệ thống gợi ý món ăn sử dụng TCP Client–Server” project.

## Current scope

The current implementation covers the SPEC 1.0 TCP path, phase 2 Web gateway, phase 3 MySQL repository, and phase 4 dataset/experiment preparation: strict length-prefixed JSON framing, PING/LIST_INGREDIENTS/GET_RECIPE/RECOMMEND, MySQL pooled connections per TCP handler, B0/P1 ranking, bounded server handlers, JSONL server logs, CLI client, FastAPI HTTP routes, Jinja2 templates, responsive Vietnamese UI, and Web-to-TCP integration tests. The additive phase 4 dataset is loaded with [source/database/mysql_expanded_seed.sql](source/database/mysql_expanded_seed.sql) and never deletes the old fixture rows. Benchmark and B0/P1 comparison scripts are in [scripts/](scripts/); their CSV files must be generated by running them against the configured MySQL database.

The verified local interpreter is Python 3.13.7. The TCP core uses only the standard library.

## Run

Copy `.env.example` to `.env`, set a MySQL account/database, then run [source/database/database.sql](source/database/database.sql) and [source/database/mysql_seed.sql](source/database/mysql_seed.sql) in MySQL Workbench. To copy the preserved SQLite data instead, run:

```powershell
Copy-Item .env.example .env
python -m source.database.migrate_sqlite_to_mysql --sqlite data/recipes.db
```

To add the phase 4 Vietnamese dataset without deleting existing data, run [source/database/mysql_expanded_seed.sql](source/database/mysql_expanded_seed.sql) in MySQL Workbench using an account with INSERT/UPDATE permission. It changes the metadata version to `vi-v2-50-recipes` after successful execution.

After the additive seed, run [source/database/mysql_recipe_instructions_update.sql](source/database/mysql_recipe_instructions_update.sql) to refine the original recipes 1–10 and set the final dataset version to `vi-v2-50-recipes-r1`.

Start the MySQL-backed TCP Server:

```powershell
python -m source.server.main
```

In a second terminal, start the Web gateway after the TCP server is running:

```powershell
python -m uvicorn source.web.main:app --host 127.0.0.1 --port 8000
```

Open <http://127.0.0.1:8000/>. The Web gateway opens a real TCP socket for every HTTP operation; it does not read MySQL/SQLite or import the ranking module.

Use the configured interpreter if `python` is not the selected command: `C:/Users/Admin/AppData/Local/Programs/Python/Python313/python.exe`.

Run tests with `python -m pytest`. The suite covers framing, ranking, ten concurrent TCP clients, TCP failure cases, HTTP validation, Web pages, Web-to-TCP routing, TCP outage response, and conditional MySQL integration. After loading the expanded dataset, run `python scripts/benchmark_tcp.py` and `python scripts/compare_algorithms.py` to create real CSV/log evidence.
